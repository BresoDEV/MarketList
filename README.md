

# 🛒 MarketList

Um aplicativo web simples e prático para montar, organizar e compartilhar listas de compras de mercado.

---
Site: https://bresodev.github.io/MarketList/

## 🛍️ Visão Geral

- Crie e edite listas de itens de supermercado.
- Armazene suas listas localmente no navegador (sem dependência de nuvem).
- Importe listas compartilhadas por amigos ou familiares.
- Compartilhe suas listas de forma rápida e prática via link ou arquivo.
- Privacidade e controle total: os dados ficam criptografados e armazenados apenas no dispositivo.
